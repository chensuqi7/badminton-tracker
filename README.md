# 羽球日记 · MY BADMINTON 3.0.1

[打开羽球日记](https://chensuqi7.github.io/badminton-tracker/)

首页用于日常一键扣课、补记和购课。流水页可编辑、筛选和删除记录。开销页可按月、年和分类查看支出，可排除一次性购课支出，设置支持月度预算。开关只影响开销页的总额、笔数、预算比较、图表和明细，首页与年度统计继续反映全量账单。统计页显示训练日历、连续完成周数、消费趋势及课时成本。

## 本地试用

在项目根目录执行 `python3 -m http.server 8000 --bind 127.0.0.1`，然后访问 `http://localhost:8000/`。应用使用相对地址和零第三方运行时依赖。首次联网加载后，Service Worker 会缓存页面及全部静态资源。

## 课时与消费

期初默认 22 节，之前抵消的超课无需再次登记。校准期初与增减调整均保留流水。赠送训练只计训练次数，赠送课时增加余额。购课余额增量为购买加赠送减本次欠课抵扣。费用由购课流水生成，购课编辑、改类型或删除会同步重算账单。补录以往金额请在「开销」新增支出并选择「历史培训补录」，课时余额保持原样。培训购课支出占比按关联购课来源统计。

一级分类固定为打球费用、球鞋服饰、球拍装备、羽球耗材、穿线维护和其他。旧培训费用与场地费用归入打球费用，旧其他费用归入其他。迁移保留来源、关联 ID 和修改历史，并备份原 V3 账本。

金额以整数分保存。课程成本按日期先购先用，实际支付金额平摊至购买与随购赠送课时，退课移除最近批次余量。期初、独立赠送及缺少实付数据的消耗标为未知。余额与预计剩余周数按每周一节估算。耗尽日期用于训练规划。

## 保存与恢复

数据仅在当前浏览器或已安装网页应用的本地存储中。V3 首次读取 V2 流水时会先备份原始值，再保存已校验的 V3 账本。原存储键保留。V3 JSON 包含课时、手工支出、设置与修改历史，关联费用从购课记录重建。也可恢复 V2 JSON 备份。恢复前会确认，并保存当前 V3 原始值。两类 CSV 分开导出，恢复使用 JSON。

更换设备、浏览器或独立应用环境时，先导出 JSON，再在新环境导入。遇到迁移失败，可从设置导出原始数据。保留站点数据可保留账本。

## 安装和更新

用 iPhone Chrome 打开正式地址，点「分享 → 添加到主屏幕 → 添加」。如有「作为网页 App 打开」开关，开启后再添加。首次联网从图标打开，待缓存安装后即可测试离线启动。

GitHub Pages 使用个人仓库 `main` 根目录并强制 HTTPS。更新静态资源时同步更新 `sw.js` 的缓存版本与文件清单。提交并发布后，核对 Pages 线上资源与提交一致。旧界面可联网关闭并重新打开以加载新缓存。
